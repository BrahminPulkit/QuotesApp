# Quotes App — React Starter

A React learning repository intended as a starting point for a quotes interface.
The current application is the Create React App starter screen; quote browsing
and API integration have not yet been implemented.

## Run locally

```bash
cd front-end
npm ci
npm start
```

## Current status

The source is in `front-end/src/` and dependencies are in
`front-end/package.json`. The starter screen identifies the project; quote-specific features remain future work.
This repository is a learning scaffold rather than a completed portfolio app.
